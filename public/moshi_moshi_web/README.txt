MOSHI MOSHI MAID CAFÉ — PROTOTIPO E-COMMERCE KAWAII

CONTENIDO
- index.html: página principal con menú, promociones, eventos y ubicación.
- styles.css: diseño responsive con estética kawaii rosa/lila, stickers, tarjetas, animaciones y estados hover.
- Tailwind CSS v3 por CDN: utilidades responsive y de diseño; necesita conexión a internet para cargar el framework. El CSS propio conserva el aspecto principal si el CDN no carga.
- script.js: filtros, carrito, cantidades, checkout, ticket imprimible y WhatsApp.
- assets/: logo, personaje maid, fotos ilustrativas de comida, afiches de promos y eventos.

CÓMO ABRIR
1. Descarga y descomprime el archivo ZIP entregado en el chat (por ejemplo, MoshiMoshi_Tailwind_Pro_v3.zip).
2. Abre la carpeta moshi_moshi_web.
3. Haz doble clic en index.html para abrir la web en el navegador.
4. Para cargar Tailwind CSS y las fuentes de Google, mantén conexión a internet. Si no hay conexión, el CSS propio conserva la mayor parte del diseño.

FUNCIONES INCLUIDAS
- Menú con filtros por categoría y tamaños Chibi/Sempai.
- Carrito con cantidades, eliminación y subtotal.
- Checkout con datos del cliente y selección entre recojo y delivery.
- Al elegir RECOJO, se ocultan y desactivan los campos de dirección; no se solicita ubicación.
- Al elegir DELIVERY, se solicitan dirección y referencia.
- Selección de pago QR (pendiente de integrar el QR bancario oficial) o efectivo.
- Generación de ticket de recojo/comprobante con número de pedido, cliente, productos, subtotal y modalidad.
- Botón para imprimir el ticket o resumen del pedido.
- Enlace a WhatsApp con el resumen para que el local confirme el pedido.
- Sección de promociones: Moshi Amigos, Promo Enamorados y Soldado Caído.
- Sección de eventos/anuncios: Tanjoubi Moshi 2026 y Chidori Fest (24–25 de octubre de 2026).

IMPORTANTE ANTES DE PUBLICAR
- Los pedidos no se guardan en una base de datos ni llegan automáticamente al local. El cliente debe enviar el resumen por WhatsApp.
- El pago QR no se procesa todavía. Moshi Moshi debe proporcionar su QR bancario oficial para integrarlo; en esta versión el estado queda pendiente de confirmar.
- Las promociones son afiches compartidos por la marca; confirmar vigencia, precios y condiciones antes de tratarlas como ofertas activas.
- Las imágenes de comida son ilustrativas. Sustituirlas por fotos reales de los productos servidos.
- El costo de delivery debe confirmarse según zona.
- El precio del Ramen Titán Colosal no se distingue con claridad en el menú proporcionado; el sitio invita a consultarlo por WhatsApp.
- Para producción se recomienda conectar una base de datos, validar pedidos en servidor y configurar correctamente los medios de pago.
